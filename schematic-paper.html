How it works
  1. Select a station on the map with the arrow keys, or click it. The lines through it light up in the signal color.
  2. Change tokens in the Tokens panel. Every change redraws the map at once, so keep the map in view while you work.
  3. Open a color to get the picker. Save color sets to the three theme slots and press c to cycle them.
  4. Copy the result from Output as CSS variables or DTCG JSON.

This window stays open while you work. Drag its title bar, or focus the grip and use the arrow keys.

Color gates

Changes that would make text unreadable are refused. The map keeps the last passing color.

  • Ink on ground needs 4.5:1. It carries every label.
  • Signal on ground needs 4.5:1. It carries the focus ring and sits behind highlighted text.
  • Signal on ink should reach 3:1, but it is advisory. Active lines are also outlined and listed under Selected station, so color is never the only cue.

In the picker, the shaded part of each track would fail. When a value is refused, use the nearest passing button to land on the closest color that passes.

To switch all three colors at once, for example from dark to light, type colors #ground #ink #signal.

Themes

Three slots hold color sets in this browser only. Save from the Themes list in the Tokens panel, or select an empty slot in the top bar to save the current colors. Press c to cycle, or type theme 2.

Use Rename on a saved theme to name it and its colors. You can also type name 2 Night shift.
